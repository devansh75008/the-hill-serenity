## ⚙️ Technical Integrations Guide

### 1. WhatsApp Instant Reservation Dispatch (Already Active)
When a guest fills out the reservation form, `app.js` automatically formats all guest parameters (Name, Suite, Dates, Guests, Diet, Notes, Reference Code) and opens WhatsApp:
```javascript
const waUrl = `https://wa.me/91XXXXXXXXXX?text=${encodedWa}`;
```
*Action required:* In `app.js` and `index.html`, replace `919876543210` with your actual WhatsApp business number.

### 2. Payment Gateway (Razorpay Integration)
To enable instant online advance deposits:
1. Create an account at [Razorpay.com](https://razorpay.com).
2. Generate API Keys (Key ID & Key Secret).
3. Use Razorpay Payment Links or drop this snippet into the booking modal:
```html
<script src="https://checkout.razorpay.com/v1/checkout.js"></script>
<script>
function triggerRazorpayDeposit(amountInINR, refCode) {
  var options = {
    "key": "rzp_live_YOUR_KEY_HERE",
    "amount": amountInINR * 100, // paise
    "currency": "INR",
    "name": "The Hill Serenity",
    "description": "Pre-Launch Advance Deposit Ref: " + refCode,
    "image": "https://thehillserenity.com/favicon.png",
    "handler": function (response){
      alert("Payment Successful! Payment ID: " + response.razorpay_payment_id);
    },
    "prefill": {
      "name": document.getElementById("guestName").value,
      "email": document.getElementById("guestEmail").value,
      "contact": document.getElementById("guestPhone").value
    },
    "theme": { "color": "#1A3026" }
  };
  var rzp1 = new Razorpay(options);
  rzp1.open();
}
</script>
```

### 3. Hotel Channel Manager & Property Management (Cloudbeds / Sirvoy / Staah)
If you decide to use Cloudbeds or Sirvoy for multi-channel inventory sync (Airbnb, Booking.com, MakeMyTrip):
- You can embed the Cloudbeds booking widget directly into the `#heroBookingBar` container by swapping the standard `<form>` for their iframe script:
```html
<!-- Example Cloudbeds Widget Embed -->
<div id="cloudbeds-booking-container"></div>
<script src="https://hotels.cloudbeds.com/widget/load/YOUR_PROPERTY_ID"></script>
```

## 🚀 Free Instant Hosting & Deployment Options

You can take this website live in under 3 minutes without writing any backend server code:

### Option A: Netlify (Recommended - 60 Seconds)
1. Go to [netlify.com](https://www.netlify.com) and create a free account.
2. Drag and drop the `the-hill-serenity` folder directly onto the Netlify dashboard.
3. Your site is immediately live with a free SSL certificate (`https://your-site.netlify.app`).
4. In Netlify settings, connect your custom domain (e.g. `thehillserenity.com`).

### Option B: Vercel
1. Install Vercel CLI: `npm install -g vercel` or upload to GitHub.
2. Run `vercel` inside the `the-hill-serenity` directory.
3. Assign your custom domain in the Vercel dashboard.

### Option C: Traditional cPanel / Hostinger / GoDaddy
1. Compress `index.html`, `styles.css`, and `app.js` into a `.zip` archive.
2. Upload and extract into your hosting account's `public_html` directory.
